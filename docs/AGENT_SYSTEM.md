# OmniDesk AI — Specialized Multi-Agent System

OmniDesk AI implements 8 specialized domain agents under `ai/app/agents/`:

1. **Executive Agent (`executive_agent.py`)**: Business Health Index synthesis, gross revenue & profit aggregation.
2. **CRM Agent (`crm_agent.py`)**: Sales leads analysis, neglected account follow-ups, and lead conversion.
3. **Project Agent (`project_agent.py`)**: Project risk evaluation, milestone tracking, and delayed workspace detection.
4. **Task Agent (`task_agent.py`)**: Task backlog analysis, priority scoring, and workload rebalancing.
5. **Finance Agent (`finance_agent.py`)**: Invoiced receivables, overdue cash flow forecasting, and payment confirmation enforcement.
6. **Document Agent (`document_agent.py`)**: Workspace-isolated semantic RAG search and source document citation.
7. **Risk Agent (`risk_agent.py`)**: Operational anomaly detection, risk scoring, and mitigation recommendations.
8. **Notification Agent (`notification_agent.py`)**: Alert dispatching.
