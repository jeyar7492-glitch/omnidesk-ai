# OmniDesk AI v1.0.0 — User Guide & Workspaces

## 1. Overview
OmniDesk AI is an enterprise agentic work operating system designed for cross-functional teams.

## 2. Navigating Workspaces

### 2.1 Employee Workspace (`/my-work`)
- **My Tasks**: View today's assigned tasks and target deadlines.
- **My Meetings**: Review upcoming scheduled syncs.
- **AI Focus Recommendations**: Personalized intelligent guidance on priority execution.

### 2.2 Manager Hub (`/manager`)
- **Team Capacity & Workload**: Review workload distribution and prevent burnout.
- **SLA Compliance**: Track task delivery velocity.
- **Blocker Identification**: Detect delayed dependencies.

### 2.3 Executive Intelligence (`/executive`)
- **Financial KPIs**: Gross Invoiced Revenue, Collected Payments, Outstanding Receivables, Net Profit.
- **CRM Pipeline**: Active deal values and stage progression.

## 3. Core Modules

### 3.1 Task Management (`/tasks`)
- **6-Column Kanban Drag-and-Drop**: Backlog, To Do, In Progress, Review, Blocked, Done.
- **Calendar & List Views**: Flexible task visualization.

### 3.2 Finance & Invoicing (`/finance`)
- **Invoice Generation**: Add line items, calculate taxes, print PDF-ready statements.
- **Payment Recording**: High-risk payments require cryptographic confirmation.

### 3.3 Knowledge Center (`/documents`)
- **Document Vault**: Store corporate policies, SOPs, and project documentation.
- **RAG Vector Search**: Query documents conversationally via AI Assistant.

### 3.4 Enterprise Communication (`/communication`)
- **Channels & Direct Messages**: Public channels, private rooms, threads, and pinned messages.

### 3.5 Global Search (Ctrl + K / Cmd + K)
- Instant lookup across Projects, Tasks, Customers, Invoices, Documents, and Meetings.
